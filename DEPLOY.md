# Деплой HexNetGroup на Vercel

Проект уже настроен как статический сайт. Сборка и переменные окружения не нужны.

## Публикация через терминал

Откройте PowerShell в папке проекта и выполните:

```powershell
npx vercel@latest login
npx vercel@latest link
npx vercel@latest --prod
```

При первом запуске:

- выберите свой аккаунт или команду;
- создайте новый проект с именем `hexnetgroup`;
- корневая папка — текущая (`.`);
- Framework Preset — `Other`;
- Build Command и Output Directory изменять не нужно.

После последней команды Vercel покажет production-адрес вида
`https://hexnetgroup.vercel.app`.

## Подключение домена

В панели Vercel откройте проект → **Settings → Domains**, добавьте домен и
установите DNS-записи, которые покажет Vercel. HTTPS будет подключён автоматически.

## Следующие обновления

После изменения файлов сайта достаточно снова выполнить:

```powershell
npx vercel@latest --prod
```

Папка `.vercel` создаётся после команды `link` и содержит локальную привязку
к вашему аккаунту. Она исключена из Git и не должна передаваться другим людям.
